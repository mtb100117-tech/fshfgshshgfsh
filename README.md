# Языки детям

Обучающее приложение для детей 5–10 лет: английский, арабский, китайский.
PyQt6, офлайн-первый подход, звук + текст + картинки.

## Установка

1. Установить Python 3.11.
2. Скопировать проект в любую папку.
3. Запустить `run.bat` — он создаст `venv` и поставит зависимости из `requirements.txt`.

## Первый запуск

Если `content/en/lessons.json` и другие JSON отсутствуют — сгенерировать контент:

```bat
.\venv\Scripts\python.exe generate_content.py
